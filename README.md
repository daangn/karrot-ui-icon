# karrot-ui-icon (legacy)

- 현재는 [seed-icon repository](https://github.com/daangn/seed-icon)에서 관리되고 있습니다.

Figma를 진실의 원천으로 하는 Icon 저장소

## SVG

```ts
import homeSvgUrl from "@karrotmarket/karrot-ui-icon/svg/icon_home.svg";
```

## React Component

> 현재 리액트 컴포넌트는 최대한 [`@seed-design/icon`](https://github.com/daangn/seed-design/tree/main/packages/icon)을 사용해주세요.

```tsx
import HomeSvg from "@karrotmarket/karrot-ui-icon/lib/react/IconHome";
```
